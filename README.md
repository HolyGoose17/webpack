# Webpack SPA 

This app renders card with products, show products' details, filtered products by category, show price and you can add product in your cart. If you need to authorize or to register in this app, you can do it.

# Stack

-Typescript
-Redux Toolkit
-RTK Query
-Webpack
-Rest API(dummyJSON)
-Material UI

# Install & Started

1. Clone repo
git clone https://github.com/HolyGoose17/webpack.git

2. Go in correct folder
cd webpack

3. Install dependencies
npm install / yarn i

4. Build project
npm run build

5. Start project
npm run start
